# Elvanto link V1 smoke test (2026-10-12)

Plan Task V1, run against branch `feat/elvanto-link-app` at `5a4d222`. Nothing touched prod.

## Setup

- **Port 4300 was busy** (another process), so the server ran on **4320**.
- No watch mode: `PERSISTENCE=memory PORT=4320 LINK_SYNC_TOKEN=<throwaway, 32 chars> npm run start` (that is `tsx src/index.ts`).
  `ELVANTO_FORMS_LIVE` was not set. The server ran in the background and was stopped at the end. Port 4320 was confirmed closed after the stop.
- Token: `node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"`. It was kept in a scratchpad file only and is not in this document.
- Fixtures: a node script copied the four `push-*.json`, `claim-request.json` and `result-request.json` to the scratchpad. In the copies, `takenAt` is now, and service 1 has `ymd` = today (Brisbane) and `startsAt` = today 18:30 Brisbane. Afterwards `git status --porcelain src/tests/fixtures` printed nothing.
- Curl helpers (`$B` = `http://localhost:4320`, `$LT` = sync token, `$AT` = the admin session token from `POST /auth/login` with `admin`/`<demo password>`):
  ```sh
  j(){ curl -s -w '  [HTTP %{http_code}]\n' "$@"; }
  sync(){ j -X POST "$B$1" -H "Authorization: Bearer $LT" -H 'Content-Type: application/json' --data-binary "@$2"; }
  sess(){ local t=$1; shift; j -H "Authorization: Bearer $t" -H 'Content-Type: application/json' -H 'x-device-id: smoke' -H 'x-device-label: curl' "$@"; }
  ```
- The shared switch was set to Shadow as admin with `sess $AT -X PATCH $B/settings -d '{"ministryConfig":{"modules":{"newYouthForms":"shadow"}}}'` → 200.
  Afterwards, `/link/status` gave 200 for admin and 404 `MODULE_DISABLED` for director.

## Observations (not failures; for the owner)

1. A `checkIn` for a roster person of kind `other` (not on the door list) was accepted (`saved`).
2. `resolved landed:true` keeps the old `unclear` `detail` ("Elvanto may not have saved this.") on what is now a `sent` row. The contract only says `landed` is set.
3. Log rows for `replay` items, and the `LINK_ID_REUSED` refusal, have no `target_kind/id/name`.
4. Pushes are accepted while the switch is Off, so the mirror stays fresh. Only claim leasing stops.
5. `GET /link/checkin` gave `defaultServiceTimeId: null` at 07:40 Brisbane for an 18:30 service that day, so the SPA opened the "Pick a service" sheet first.
